# Courier-Management-System
Courier Management &amp; Shipment Tracking System is a full-stack Java application designed to simplify the management of courier services, shipment orders, and package tracking.

The project follows a multi-module architecture consisting of:

Project-api – REST API responsible for business logic, statistics and order processing.
ProjectApp – Web application built with Spring Boot and Thymeleaf that communicates with the API and provides the user interface.

The application allows customers to create shipments, calculate delivery prices, track packages, and enables administrators to manage couriers, shipments and statistics.
